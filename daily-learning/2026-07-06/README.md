# Day 8 — C# 模板方法模式 (Template Method Pattern)

> **日期:** 2026-07-06  
> **难度:** ★★☆☆☆

---

## 🎯 今日主题

模板方法模式在父类中定义算法的骨架，将具体步骤延迟到子类中实现。子类可以覆写特定步骤，但不能改变算法的结构 — 就像填空题，父类出好试卷，子类只管填答案。

---

## 📖 核心知识点

| # | 知识点 | 说明 |
|---|--------|------|
| 1 | 算法骨架 | 父类定义固定流程，用 `sealed` 防止子类破坏 |
| 2 | 抽象步骤 | `abstract` 方法 — 子类必须实现的具体步骤 |
| 3 | 钩子方法 (Hook) | `virtual` 方法 — 子类可选覆写，有默认行为 |
| 4 | 具体方法 | 所有子类共用的逻辑，放在父类避免重复 |
| 5 | 好莱坞原则 | "别打电话给我们，我们会打给你" — 父类控制一切 |
| 6 | 药水酿造 | 生命药水 / 法力药水 / 爆炸药水 — 相同流程不同配方 |
| 7 | 任务系统 | 击杀 / 收集 / 护送 — 所有任务共享生命周期 |
| 8 | 回合 AI | 史莱姆 / 火龙 / 哥布林 — 统一回合流程 |
| 9 | UI 面板 | 设置 / 背包 — 统一的显示→交互→关闭流程 |
| 10 | 协程模板 | 配合 `IEnumerator` 实现异步酿造 |
| 11 | sealed 关键字 | 锁定模板方法，子类不可覆写 |
| 12 | 模板方法 vs 策略 | 模板填空 vs 策略替换整个算法 |

## 💡 一句话总结

> 把"做一件事的固定流程"写在父类里，把"每一步怎么做"交给子类 — 就像填空题，答题顺序已定好，你只需要填每个空格。控制权反转是好莱坞原则的核心。

## 🧪 运行方式

将 `TemplateMethodPattern.cs` 放入 Unity 项目的任意 `Scripts` 文件夹中，在场景中创建空 GameObject 并挂载 `TemplateMethodDemo` 组件，运行后即可在 Console 中看到所有演示输出。
