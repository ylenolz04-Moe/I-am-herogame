## 🎯 今日主题

今天学两个基础但重要的知识点：

### 🌳 树形结构 (Binary Tree)

**树 = 生活里随处可见的层级结构** — 公司组织架构、电脑文件夹、游戏技能树、朋友圈评论...全是树！

二叉树是最简单的树：**每个节点最多有两个分支**（左和右）。二叉搜索树(BST)更是厉害 — 100万条数据，最多20步就能找到目标！

**游戏里的树：** 技能树、对话树、AI行为树、场景层级、UI层级...

### 📦 C# 结构体 (struct)

**struct = 轻量级的 class** — 当你只需要一个小数据容器时，用 struct 比 class 更快、更省内存。

Unity 里你每天都在用 struct：`Vector3`, `Color`, `Quaternion`, `Rect`...它们全部是 struct！

## 📖 核心知识点

### 🌳 树形结构 (6个核心知识点)

| # | 知识点 | 说明 |
|---|--------|------|
| 1 | 树的术语 | 根节点(Root)、叶子(Leaf)、父/子节点、深度(Depth) — 5个词就够了 |
| 2 | 二叉树节点 | 每个节点 = 数据 + 左引用 + 右引用 |
| 3 | 二叉搜索树(BST) | 左边放比当前小的，右边放比当前大的 — 查找极快 O(log n) |
| 4 | 递归操作 | 树和递归是好朋友 — "把大树拆成小树，直到最简单" |
| 5 | 三种遍历 | 前序(根→左→右)、中序(左→根→右)、后序(左→右→根) — 只有"访问自己"的位置不同 |
| 6 | 游戏技能树 | 实战 — 把二叉树改成技能树系统 |

### 📦 C# 结构体 (10个核心知识点)

| # | 知识点 | 说明 |
|---|--------|------|
| 7 | 值类型 vs 引用类型 | **struct 赋值=复印文件** (独立) vs **class 赋值=共享链接** (同一个) |
| 8 | struct 语法 | 和 class 几乎一样 — 把 `class` 关键字换成 `struct` |
| 9 | struct 有方法 | struct 也能有构造函数、方法、属性 |
| 10 | 栈 vs 堆 | struct 在栈上(快、无GC) vs class 在堆上(灵活、需要GC) |
| 11 | readonly struct | 不可变结构体 — 像 Vector3 一样，修改就返回新的 |
| 12 | struct 的限制 | 不能继承、不能无参构造(C#10前)、字段不能有初值(C#10前) |
| 13 | 适用场景 | 数据 < 16字节、不需要继承、频繁创建 → 用 struct |
| 14 | struct 数组 | 内存连续排列，CPU缓存友好，遍历快 |
| 15 | Unity 实战 | 武器属性、掉落信息、路点、敌人生成 — 轻量数据都用 struct |
| 16 | class 默认选择 | 不确定用啥？先用 class，性能瓶颈出现再优化成 struct |

## 💡 一句话总结

> **树：** 数据像树枝一样分叉 — 根出发，左右分，递归找，三种顺序各有用。
