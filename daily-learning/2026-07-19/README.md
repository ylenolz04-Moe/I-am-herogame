# Day 12 — C# 建造者模式 (Builder Pattern)

> **日期:** 2026-07-19  
> **难度:** ★★☆☆☆

---

## 🎯 今日主题

建造者模式分步骤构建复杂对象。就像在 Subway 点三明治 — 选面包→选肉→选蔬菜→选酱料→最后"Build"出来。不用记构造函数第7个参数是什么，一步一步来，清晰明了。

---

## 📖 核心知识点

| # | 知识点 | 说明 |
|---|--------|------|
| 1 | 建造者四要素 | Product / Builder / ConcreteBuilder / Director |
| 2 | 武器建造者 | SwordBuilder(剑)/BowBuilder(弓) — 同一流程不同加成 |
| 3 | Director 指挥者 | WeaponSmith 封装预设配方 (新手剑/传说剑/暗影弓) |
| 4 | 流式建造者 | `builder.SetA().SetB().Build()` — C# 最流行的写法 |
| 5 | 角色预设 | 战士/法师/射手 — 一行代码创建完整角色 |
| 6 | UI 弹窗构建 | 删除确认/提示/奖励弹窗 — 灵活组合 |
| 7 | 不可变对象 | Builder 为唯一入口，构建完就锁定 |
| 8 | Builder vs Factory | 工厂一步创建，建造者分步组装 — 经典对比 |

## 🔗 与其他学习日的关系

- **Day 9 (工厂方法):** 工厂一步创建 → 建造者分步组装 — 互补关系
- **Day 11 (外观):** 外观简化子系统调用 → 建造者简化对象构建

---

## 💡 一句话总结

> 建造者 = 分步骤把对象"搭"出来，每一步都看得见。工厂 = "给我一个XX"，建造者 = "我要这样的XX：…"。参数多了用建造者，对象简单用工厂。

---

## 🧪 运行方式

将 `BuilderPattern.cs` 放入 Unity 项目的任意 `Scripts` 文件夹中，在场景中创建空 GameObject 并挂载 `BuilderDemo` 组件，运行后即可在 Console 中看到所有演示输出。
